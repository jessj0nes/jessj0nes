This work, accepted at the **CVBMC Workshop at ICPR 2026**, presents **CoralLite**, an annotated μCT scan dataset of entire calcareous coral skeletons and a first corallite deep learning reconstruction baseline.

Key contributions:

- Combines fully quantified volumetric segmentations with cross-slice linking for 3D corallite visualisation up to colony scale.
- Proposes and evaluates a hybrid V-Trans-UNet architecture for segmenting tiled μCT virtual slabs of _Porites_ sp. colonies.
- Publishes the full dataset of 697 μCT slices, 37 partial or full slice annotations, and all network weights and source code for reproducibility.

**arXiv preprint:** [arXiv:2605.15093](https://arxiv.org/abs/2605.15093)
